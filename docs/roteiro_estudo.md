# Roteiro De Estudo

## Fase 1 - Fundamentos

1. Importar os CSVs.
2. Conferir tipos de dados no Power Query.
3. Remover erros e valores nulos, se aparecerem.
4. Criar os relacionamentos do modelo estrela.
5. Marcar `dim_calendario` como tabela de datas.

Resultado esperado: modelo funcionando com contagem de vendas por mes, loja e categoria.

## Fase 2 - DAX Essencial

1. Criar medidas de receita, custo, lucro, margem e quantidade.
2. Criar medidas de pedidos, ticket medio e clientes unicos.
3. Comparar indicadores por ano, mes, regiao, loja, categoria e canal.

Resultado esperado: primeira pagina executiva com KPIs e graficos de tendencia.

## Fase 3 - DAX Intermediario

1. Criar receita do ano anterior.
2. Criar variacao percentual contra ano anterior.
3. Criar acumulado no ano.
4. Criar meta de receita com `TREATAS`.
5. Criar atingimento de meta.

Resultado esperado: dashboard passa de descritivo para analitico.

## Fase 4 - Dashboard

1. Pagina Executiva: receita, margem, meta, tendencia e top categorias.
2. Pagina Produtos: ranking, margem, desconto e devolucoes.
3. Pagina Lojas: desempenho por regiao, loja e vendedor.
4. Pagina Clientes: segmentos, clientes unicos, ticket e recorrencia.

Resultado esperado: relatorio navegavel, com filtros consistentes e leitura clara.

## Fase 5 - Recursos Intermediarios

1. Criar drill-through de loja.
2. Criar tooltip customizado de produto.
3. Criar bookmarks para alternar Receita, Lucro e Margem.
4. Criar painel de filtros.
5. Revisar performance no painel de desempenho.

Resultado esperado: projeto com acabamento de portfolio.
